# Guia de lectura para agentes

## Objetivo

Indicar a una IA que archivos debe leer segun la tarea, sin obligarla a cargar toda la documentacion del repositorio.

## Leer siempre al empezar

- `AGENTS.md`

## Si necesitas entender el producto y la app

Lee:

- `README.md`
- `tech_docs/manual_tecnico.md`

Si la tarea afecta al uso diario o a la interfaz de gestion, añade:

- `tech_docs/manual_usuario.md`

## Si vas a modificar codigo

Lee primero:

- `tech_docs/README.md`

Y crea o actualiza una nota tecnica en `tech_docs/` con formato:

- `YYYY-MM-DD_<tema>.md`

## Si vas a trabajar con ramas, merges o despliegue de cambios

Lee:

- `tech_docs/14_flujo_git_y_politicas_repos.md`

## Si vas a preparar version o release

Lee:

- `tech_docs/politica_versionado.md`
- `VERSION`

## Si vas a redactar una Pull Request

Lee:

- `tech_docs/14.1_plantilla_pr_vibecoding.md`

## Si necesitas contexto operativo reciente

Lee:

- `tech_docs/registro_cambios.md`

## Si la tarea toca backup o recuperacion

Lee:

- `tech_docs/manual_tecnico.md`
- `tech_docs/manual_usuario.md`
- `tools/README.md`

## Si la tarea toca monitorizacion, heartbeat o quioscos

Empieza por:

- `README.md`
- `tech_docs/manual_tecnico.md`

Y si hace falta contexto historico, busca en:

- `tech_docs/2026-*.md`

## Si la tarea toca UX, textos o flujos web

Lee:

- `tech_docs/manual_usuario.md`
- `tech_docs/manual_tecnico.md`
- `tech_docs/registro_cambios.md`

## Si la tarea tiene dudas importantes o impacto amplio

Aplicar revision adicional:

- `99_revision_integral_app`
