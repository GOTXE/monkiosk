# 14.1 Plantilla de Pull Request (IA)

Plantilla oficial para generar resúmenes estructurados de PR con IA en Vibe Coding.

## Objetivo

Generar descripciones de PR consistentes y auditables usando IA sin cambiar la estructura.

## Uso

Copia este archivo al prompt junto con el diff o los commits antes de abrir un PR.

## Reglas

- No modifiques títulos, numeración ni orden.
- No añadas ni elimines secciones.
- No uses emojis.
- No inventes nada fuera del diff o commits.
- Resumen ejecutivo máximo 4 líneas.
- Si algo no aplica, escribe `No aplica`.
- Marca áreas según archivos modificados.

## Áreas

- Core / lógica
- Core / seguridad
- Core / validación
- Core / configuración
- Core / logging
- Web / templates
- Web / API
- Web / UI
- CLI / herramientas internas
- Base de datos / migraciones
- Infra / CI-CD
- Tests
- Documentación
